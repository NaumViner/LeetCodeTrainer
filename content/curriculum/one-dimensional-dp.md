# State, transition, and order

## Overview

Dynamic programming stores answers to overlapping subproblems. Define `dp[i]` in one complete sentence before writing a recurrence.

## Recognition signals

Count ways, minimum cost, best value up to a position, and take-or-skip choices with repeated suffix or prefix states.

## Complexity

Time is the number of states times work per transition. Space can often shrink when each state needs only a fixed number of earlier values.

## Common mistakes and practice

Do not start with a table before defining state, and verify base cases independently. Practice climbing stairs, house robber, and coin change while stating state and transition aloud.
